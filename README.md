# Python Beginner Challenge - Task 2

This repository contains my completed solutions for **Task 2: Python Beginner Challenge**, covering core Python fundamentals and a command-line **Student Management System** mini-project.

## Folder Structure
- `part1_fundamentals/` - Solutions for all 7 Python fundamental topics (basics, data types & operators, conditionals, loops, strings/lists/dictionaries, functions, and file/error handling).
- `part2_mini_project/` - Menu-driven Student Management System (`student_management_system.py`) with persistent JSON storage.
- `screenshots/` - Output screenshots demonstrating the working Student Management System.

## How to Run the Project
1. Make sure **Python 3** is installed on your system.
2. Clone or download this repository and open the folder in your terminal or VS Code.
3. Run the Student Management System using:
   ```bash
   py part2_mini_project/student_management_system.py
